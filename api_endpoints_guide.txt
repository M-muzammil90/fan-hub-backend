Base URL: http://localhost:5000

--------------------------------------------------------------------------------
1. AUTHENTICATION APIs
--------------------------------------------------------------------------------

[1] USER REGISTRATION
URL: POST http://localhost:5000/api/auth/register
Access: Public
Headers: Content-Type: application/json
Body:
{
    "name": "Ahmed Raza",
    "email": "ahmed@example.com",
    "password": "Password123"
}
Explanation: Registers a new normal user with role = "user". Hashes password using bcrypt.


[2] USER LOGIN
URL: POST http://localhost:5000/api/auth/login
Access: Public
Headers: Content-Type: application/json
Body:
{
    "email": "ahmed@example.com",
    "password": "Password123"
}
Explanation: Verifies user credentials using bcrypt and returns a JWT token for authentication.


[3] FETCH CURRENT USER PROFILE
URL: GET http://localhost:5000/api/auth/me
Access: Protected (Requires User or Admin JWT Token)
Headers:
    Content-Type: application/json
    Authorization: Bearer <YOUR_JWT_TOKEN>
Explanation: Returns the profile data of the currently logged-in user based on the JWT token.
