--------------------------------------------------------------------------------
1. AUTHENTICATION APIs
--------------------------------------------------------------------------------

[1] USER REGISTRATION
URL: POST http://localhost:5000/api/auth/register
Access: Public
Headers: Content-Type: application/json
Body:
{
    "name": "Ahmed Raza",
    "email": "ahmed@example.com",
    "password": "Password123"
}
Explanation: Registers a new normal user with role = "user". Hashes password using bcrypt.


[2] USER LOGIN
URL: POST http://localhost:5000/api/auth/login
Access: Public
Headers: Content-Type: application/json
Body:
{
    "email": "ahmed@example.com",
    "password": "Password123"
}
Explanation: Verifies user credentials using bcrypt and returns a JWT token for authentication.


[3] FETCH CURRENT USER PROFILE
URL: GET http://localhost:5000/api/auth/me
Access: Protected (Requires User or Admin JWT Token)
Headers:
    Content-Type: application/json
    Authorization: Bearer <YOUR_JWT_TOKEN>
Explanation: Returns the profile data of the currently logged-in user based on the JWT token.

15. PASSWORD RECOVERY APIs
--------------------------------------------------------------------------------

[67] FORGOT PASSWORD (REQUEST RESET TOKEN)
URL: POST http://localhost:5000/api/auth/forgot-password
Access: Public
Headers: Content-Type: application/json
Body:
{
    "email": "ahmed@example.com"
}
Explanation: Generates a 32-byte secure random reset token, stores a SHA-256 hashed copy with a 10-minute expiration, and sends the password reset link to the user's email via Nodemailer. Returns a generic success response without exposing tokens or email existence.


[68] RESET PASSWORD (SUBMIT TOKEN & NEW PASSWORD)
URL: POST http://localhost:5000/api/auth/reset-password
Access: Public
Headers: Content-Type: application/json
Body:
{
    "token": "<RESET_TOKEN>",
    "password": "NewPassword123"
}
Explanation: Validates token hash and expiration. Hashes the new password using bcryptjs, updates user credentials, and invalidates the reset token to prevent reuse.
